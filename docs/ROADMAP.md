# 第一阶段实施路线

以“小任务、独立验收、每步可构建”为原则。每次实现一个里程碑；新模型无需同时阅读所有业务代码，只需读取交接文档、架构对应段落和本次涉及文件。

## M0 — 规划与初步框架（本轮）

状态：已通过编译，尚未做运行验收。

交付：App / Features / Core 目录；Track 和队列值类型；基础窗口、单文件入口、播放条、队列面板；初步 AVPlayer/系统媒体适配；架构和后续任务说明。

注意：M0 不是“功能 1–7 已完成”，后面的任务是必要工作。

## M1 — 共享应用状态与单文件播放闭环

状态：2026-10-18 已实现，Debug 构建和八项测试通过，主窗口 Preview 已渲染。实际听音、选择器和滑块手势、媒体键与多窗口人工验收仍待补，详见 HANDOFF。

依赖：M0。暂不引入数据库。

修改范围：App、PlaybackController、SystemMediaController、PlayerBar、Sidebar 的入口文案。

任务：

- 由 App 持有唯一播放控制器，注入主窗口；预览用不连接系统媒体的实例。
- 统一单文件入口的文案和行为，保留后续文件夹导入接口位置。
- 单文件打开后异步读取可播放性与时长，处理取消/损坏/不存在文件；临时授权有对应生命周期。
- 修正播放状态同步、切歌时旧回调失效、seek 拖动/键盘行为和资源清理。
- 维护窗口内基础布局，不提前填充专辑和艺术家业务。

验收：

- Debug 构建通过；运行后手动打开一个测试音频，能播放/暂停/调音量/拖进度。
- 两次快速切换文件没有旧回调覆盖当前时长或状态。
- 暂停、自然播完、错误三种状态可区分；无文件时控件禁用。
- 不出现重复媒体键处理器；预览不注册媒体键。

交接：记录测试音频格式和实际运行结果；没做听音或媒体键测试必须注明。

## M2 — GRDB、授权与资料库基础

实现范围：GRDB 固定 7.11.1，LibraryStore 与文件夹授权两个 actor，LibraryController 和文件夹管理 sheet。验证结果与仍需人工验收的沙盒跨启动行为见 HANDOFF。

依赖：M1。此项可以再拆为 M2a 数据库、M2b 书签。

修改范围：Xcode 工程依赖/entitlements、Core/Library、App 组合层、Tests。

任务：

- SPM 引入 GRDB，创建迁移和 LibraryStore；按架构约定实现 folder / track / importIssue。
- SQLite、Artwork 目录均使用 Application Support；预览和测试注入临时或内存 store。
- 创建 FolderAccessController，支持选目录、持久化和恢复 security-scoped bookmark。
- 对授权过期、目录不存在、数据库失败提供明确状态；取消选择不显示错误。
- 复用 M1 已创建的独立 XCTest target，新增数据库/授权测试，避免 Tests 被 App 同步目录编入。

验收：

- 首次创建、再次打开、重复 upsert、路径去重、按 folderID 查询均有测试。
- 手动选择测试目录后退出再启动，仍能读取其内文件；撤销访问/目录移动时能重新授权。
- 不写入真实用户音乐目录，不静默丢弃数据库错误。

技术约定：先准备新授权、再写库、最后提交租约；重复路径保留原 ID，写库失败不打断旧租约。测试宿主通过 scheme 中的 `LIQUIDMUSIC_TESTING=1` 避免打开真实资料库。

## M3 — 后台索引、元数据与封面

状态：2026-10-18 已实现，Debug 构建和 37 项测试通过，进度/报告/文件夹管理与审阅预览已验证。真实沙盒、文件选择器与扫描期间听音的人工验收待补，详见 HANDOFF。

依赖：M2。建议拆为 M3a 元数据、M3b 扫描、M3c 封面和导入 UI。

修改范围：Core/Library、Features/Library 的导入状态、Sidebar 导入入口、Tests。

任务：

- 首次空库引导选择音乐文件夹，已导入后仍可继续添加或重新扫描。
- 后台递归扫描扩展名集合，处理隐藏文件、符号链接、大小写扩展名和重叠根目录去重。
- 异步读取 common metadata 及必要格式标签，标题/艺术家/专辑/封面回退规则明确。
- 根据实际解码能力接受或跳过 FLAC，损坏文件不中断全库扫描。
- 生成封面缩略图缓存；批量写库，展示发现/索引进度、取消、完成摘要和问题详情。
- 重扫生成可审阅方案；覆盖已有索引或清理失踪索引前展示具体条目，等待用户确认。仅完整枚举结束后才可提出清理，取消/无权限不误删；不删除或覆盖音频文件。

验收：

- 临时嵌套文件夹包含 m4a/mp3/wav/aiff/flac 候选、非音频、损坏文件，成功/跳过计数正确。
- 元数据缺失不崩溃；时长不出现 NaN；封面巨大或损坏不阻塞 UI。
- 相同文件夹导入两次不产生重复曲目；扫描中取消保留既有有效索引。
- 导入时可以移动窗口并控制播放；跨启动恢复索引无需重新扫描。

实现约定：扫描阶段不写已有索引；纯新增自动提交，其余方案由 ScanReviewView 确认。提交前重新校验文件指纹、目录权限和数据库基线；事务失败整批回滚。初版每个根目录串行读取，限制任务数量；用户取消后仅可能保留未引用的不可变封面缓存，后续缓存清理另行确认。

## M4 — 资料库浏览、搜索与分组

状态：2026-10-18 已实现，Debug 构建与 48 项测试通过（含 M4 十一项）；主窗口、专辑/艺术家浅深色和维度/空状态预览已检查。双击/悬停/排序标题的真实鼠标交互仍待人工验收，详见 HANDOFF。

依赖：M3。

修改范围：Features/Library、Sidebar、ContentView、必要的纯模型查询工具。

任务：

- LibraryViewModel 持有 section、query、sort、维度导航和资料库状态。
- 歌曲 Table 展示封面、标题、艺术家、专辑、时长；支持四种排序和实时搜索。
- 悬停出现播放按钮；双击以当前可见顺序播放；当前行显示随播放状态变化的声波。
- 专辑网格、艺术家列表，以及点入后的对应歌曲列表；有返回路径。
- 固定播放列表只提供“所有音乐”。
- 区分未导入、搜索无结果、索引中和读取失败，不用同一个空白占位掩盖错误。
- 大库搜索/排序不应反复在 View body 全量进行；使用必要的缓存或后台处理。

验收：

- 搜索匹配三个字段、数值时长排序、同名不同艺术家专辑分组有纯逻辑测试。
- 搜索后双击的队列顺序和表格一致；清除搜索恢复列表。
- 深/浅色下可读；每个 Feature 的 Preview 可打开且不产生实际副作用。

## M5 — 队列与播放模式收敛

状态：2026-10-18 已实现，Debug 构建与 72 项测试通过（M5 新增 17 项队列、4 项进度状态、3 项真实 AVPlayer 静音集成测试）。队列浅/深色、随机/空队列和播放/进度条 Preview 成功渲染。真实鼠标/键盘与听音仍待人工验收。

依赖：M4；纯队列测试可提前进行。

修改范围：PlaybackQueue、PlaybackController、QueueView、歌曲上下文菜单、Tests。

任务：

- 按 ARCHITECTURE 第 6 节确定的语义修正状态机。
- 沿用 M4 歌曲/维度表格的“下一首播放”入口，完善其队列边界；队列中同一首歌出现多次能精确跳转。
- 覆盖顺序/列表循环/单曲循环/随机，以及模式中途切换。
- 修正随机插队后重建随机候选导致的一轮内重复问题；跳转到优先条目后移除相应待播优先项。
- 进度滑块拖动期间不被时间回调覆盖；键盘可调整进度。

验收：

- 自动化用例覆盖空队列、单曲、末尾、重复 Track、插队、随机无重复、历史后退、模式切换。
- 随机测试注入确定性随机源或验证不变量，避免依赖概率和易波动测试。
- 手动快速下一首/上一首不崩溃，结束通知只作用于当前条目。

## M6 — 菜单栏、系统媒体与窗口生命周期

状态：2026-10-18 已实现，Debug 构建与 87 项测试通过（M6 新增 8 项媒体、7 项窗口测试）。真实 AppKit/SwiftUI 桥的程序化最小化/恢复与菜单栏浅深色 Preview 已验证。媒体键/控制中心、实际 Dock/菜单栏点击、Command-Q 与真实沙盒仍待人工验收，详见 HANDOFF；不能视作系统集成已完成人工验收。

依赖：M1 和 M5。

修改范围：App、MiniPlayerView、SystemMediaController。

任务：

- 挂载 MenuBarExtra，共享播放状态，打开/恢复主窗口，提供显式退出。
- 更新 Now Playing 的播放速率、进度、封面与歌曲信息；完善命令可用状态。
- 媒体键与系统 seek 操作同一播放器，注册/注销可控。
- 关闭主窗口时最小化到 Dock；Dock 和菜单栏都可恢复；Command-Q 真正退出。
- 播放不中断，不要为了关窗保活额外创建后台服务。

验收：

- 手动检验播放中点击红色关闭按钮、Dock 恢复、菜单栏恢复、Command-Q。
- 系统播放/暂停、上一首、下一首与界面一致，锁屏/控制中心显示正确曲目（按测试机器实际可用系统入口验证）。
- 多次隐藏/恢复没有多播放器、重复命令或失去窗口控制。

## M7 — 第一阶段体验验收

状态：2026-10-19 体验收尾代码已实现，Debug/Release 构建与 89 项逻辑/集成测试通过，续验新增 4 项 macOS 桌面 UI 回归；已修复隐藏侧边栏后的搜索焦点、音量 Escape 和队列缩放崩溃。主窗口宽/窄、浅深色、增加对比度、空库和千首 Table 预览已检查。人工验收未完结，自动操作与人工待验边界见 `docs/VALIDATION.md`。不要据此进入第二阶段。

依赖：M1–M6。

任务：

- 统一间距、系统字体、语义颜色、工具栏与玻璃层次；不复刻网页式卡片 UI。
- 用 ViewThatFits 或布局条件适配窄窗口；支持深浅色、减少动态效果、增加对比度、VoiceOver 标签和键盘焦点。
- 至少检查空库、少量曲目和约 1,000 条索引的交互流畅度；用测试素材，勿擅自扫描真实资料库。
- 清理重复代码、无用占位和编译警告，更新 README 的实际功能清单。
- 执行 Debug 和 Release 构建、自动化测试、下表人工测试，记录剩余限制。

### 最终需求覆盖表

| 用户需求 | 交付里程碑 | 核心人工验收 |
|---|---|---|
| 首次引导、递归扫描、进度 | M2–M3 | 取消/重复导入/无权限/跨启动 |
| 歌曲、专辑、艺术家、搜索排序 | M4 | 过滤与排序组合、维度返回 |
| 播放、进度、音量 | M1、M5 | 可听播放、快速切换、拖动和键盘 |
| 队列、下一首播放 | M5 | 重复歌曲、多次插队、随机模式 |
| 四种播放模式 | M5 | 单曲、末尾、自然结束和手动切歌 |
| Now Playing、媒体键、菜单栏 | M6 | 系统界面与主窗口一致 |
| 关闭窗口最小化到 Dock | M6 | 不断音、能恢复、能退出 |
| Liquid Glass、原生组件、深浅色 | M4、M7 | 调整窗口、辅助功能与两种外观 |
| 分层、预览、可测试 | 全程 | Preview 无副作用、模型独立测试 |

## 不进入第一阶段

均衡器、频谱、歌词、播放列表编辑、Apple Music 账户/流媒体。不要提前增加这些功能的配置 UI、权限请求或空实现。
