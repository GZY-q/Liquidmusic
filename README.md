# Liquidmusic

对标 Apple Music 的原生 macOS 本地音乐播放器。第一阶段只播放本地文件，不接入账号或流媒体。

## 当前进度

已实现 M0–M7 的框架、本地索引与浏览、播放/队列、系统集成和体验收尾代码。最低 macOS 26，Swift 6 + SwiftUI；第一阶段仍有人工待验项，详见 [验收记录](docs/VALIDATION.md)。

- App 级共享播放器，唯一主窗口和菜单栏共用状态，Preview 使用独立模拟数据。
- 工具栏与 Command-O 打开单个音频文件；异步校验音频、标签和嵌入封面，坏图/缓存失败用可关闭的非阻断提示。
- 读取进度、取消和错误提示；失败保留旧曲目，快速重选不被旧任务覆盖。
- 播放/暂停、进度、音量、播放结束重播；临时文件访问和观察者有配对清理。
- 应用菜单“设置…”（⌘,）：顶部图标分页（⌘1–⌘4，记住本次运行的最后一页），外观、菜单栏播放器、默认播放模式、音乐文件夹管理及启动音量；外观可在设置窗口预览，可恢复本页默认值，“好”保存到 SQLite，“取消”放弃草稿。
- 可开关的交叉渐入渐出，时长 1–12 秒（默认关闭，6 秒）；自动换曲时两路 AVPlayer 重叠，支持暂停/恢复。短曲缩短重叠，手动切歌和单曲循环保持直接切换。
- 顺序、列表循环、单曲循环、随机模式；随机按队列条目每轮不重复，插队不重洗剩余候选。
- 队列分为当前歌曲、接下来与播放历史；重复歌曲按独立条目跳转，回退后可沿实际历史前进。
- 进度拖动保留临时位置、释放后 seek，支持键盘写入；切歌时拒绝旧滑块回调。
- 点击播放条封面或曲名展开 Now Playing：大封面、模糊封面背景、歌曲信息、带时间进度、玻璃播放控制与音量，Esc 关闭。右侧独立歌词按钮读取同目录同名 LRC 或音频内嵌歌词，支持同步高亮、自动跟随、点击定位与手动选择本地歌词。
- 原生侧边栏、歌曲 Table、内容区底部悬浮 Liquid Glass 播放条、大封面与队列面板；900 点以下窗口的队列通过按钮弹出，跨布局阈值自动收起。
- 最小 640×520 窗口；窄内容区使用紧凑 List，播放条保持单行胶囊与单行曲名，使用系统 Liquid Glass 和原生进度 Slider；音量通过按钮弹出滑块。
- Command-F 聚焦资料库搜索，Escape 清除搜索；播放控件提供辅助功能标签和值，遵循减少动态效果、减少透明度和增加对比度设置。
- 标题/艺术家/专辑实时搜索与四种升降序排序；后台缓存查询，支持中文子串及大小写/变音符号不敏感匹配。
- 侧边栏提供可折叠的资料库、播放列表和智能列表分组；最近添加、艺术家、专辑、歌曲、固定“所有音乐”、最近播放与最常播放均可用。工具栏支持返回/前进（⌘[ / ⌘]）与歌曲列表/专辑网格切换；悬停行内播放、双击按当前可见顺序播放，右键提供“下一首播放”。
- 聆听记录在独立 SQLite 表中按音频路径保存；成功开始播放一次计一次，暂停/继续/定位不重复计数，加载失败不计数。旧资料库没有可恢复的添加时间，最近添加从首次记录开始排序；临时单文件重启后仍不会自动加入资料库。
- 专辑网格与详情使用完整专辑的稳定封面候选，缺图或坏图依次回退；异步切换拒绝迟到图片。单文件新封面贯通当前曲目展示；库内同路径仍保留原索引，缺图时提示重扫审阅。
- MenuBarExtra 迷你控制器：当前曲目、播放控制、恢复主窗口和退出。主窗口关窗转为最小化，Dock 重开和菜单栏恢复同一窗口。
- Now Playing 的标签/封面/速率/进度更新；按状态启用媒体命令并返回正确结果，封面异步加载，普通进度每 5 秒校准。
- GRDB 7.11.1 / SQLite：迁移、稳定 UUID、路径去重、事务写入和导入问题记录。
- “音乐文件夹”管理入口：只读书签保存/恢复、过期刷新、授权失败与重新授权；写库失败保留旧授权。
- 添加文件夹后自动扫描；递归发现 m4a/mp3/flac/wav/aiff/aif，跳过隐藏文件、包和符号链接，重叠目录按最具体根目录归属。
- 读取标题、艺术家、专辑、专辑艺术家、曲号/碟号及嵌入封面；ImageIO 生成最长边 512 像素的缩略图并缓存。
- 导入进度、取消、问题报告和跨启动索引恢复。重扫使用文件指纹复用未变化数据；覆盖旧索引或清理失踪索引前显示具体清单并等待确认。

物理媒体键、控制中心、Dock 点击和 Command-Q 的端到端人工验收尚待补齐。FLAC 按 AVFoundation 实际能力接受或跳过并记录，不保证所有编码变体可播放。

## 本地歌词

点击底部播放条右侧的歌词按钮打开歌词界面，Now Playing 内也有歌词入口；按 Escape 或关闭按钮返回。界面内可播放/暂停、切歌、调整进度；点击左上封面仍能查看大封面。

- 将 UTF-8 或带 BOM 的 UTF-16 歌词保存为音频同目录、同名的 `.lrc`（例如 `夜航.m4a` 对应 `夜航.lrc`）；支持 `.LRC` 扩展名。应用只读取该文件，不枚举额外目录。
- 没有可用 LRC 时读取 AVFoundation 支持的音频内嵌歌词。带时间标签的歌词逐句同步，没有时间标签则显示可选中的纯文本；不支持逐字卡拉 OK。
- 也可用“选择歌词…”打开 LRC/纯文本文件，尤其适用于仅授权了单个音频、无法读取相邻文件的情况。手动选择仅用于本次查看，不写回音频或数据库；“自动查找”恢复同名文件/内嵌歌词来源。
- 点击歌词可跳到对应位置；手动滚动会暂停自动跟随，重新勾选“跟随播放”恢复。时间范围外的歌词不能点击定位。读取失败可重新读取或更换文件。
- 文件及多时间标签展开后的文本上限 1 MiB，最多 10,000 行/标签。没有联网搜索或下载歌词。

## 运行与验证

用 Xcode 打开 `Liquidmusic.xcodeproj`，选择 `Liquidmusic` scheme。其他开发者按自己的签名环境配置 Development Team。

```sh
xcodebuild -project Liquidmusic.xcodeproj \
  -scheme Liquidmusic -configuration Debug \
  -derivedDataPath /tmp/Liquidmusic-build \
  CODE_SIGNING_ALLOWED=NO build
```

```sh
xcodebuild -project Liquidmusic.xcodeproj \
  -scheme Liquidmusic -configuration Release \
  -derivedDataPath /tmp/Liquidmusic-build \
  CODE_SIGNING_ALLOWED=NO build
```

```sh
xcodebuild -project Liquidmusic.xcodeproj \
  -scheme Liquidmusic -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath /tmp/Liquidmusic-build \
  CODE_SIGNING_ALLOWED=NO test
```

Intel Mac 将测试 destination 的 arch 改为 `x86_64`。首次解析 GRDB 需下载上游仓库；版本已锁定在 Package.resolved。测试使用临时目录和合成音频素材，播放器静音，不扫描用户音乐文件夹。共享 scheme 的 TestAction 必须使用自己的环境（shouldUseLaunchSchemeArgsEnv=NO）；M6 修复了此前隔离变量被运行环境覆盖的问题，并通过 AppRuntime 识别 XCTest/Preview。媒体测试使用替代传输层，不触碰真实系统控制中心。运行测试不需要安装 FFmpeg。

独立桌面 UI 回归（需要 macOS 图形会话；运行期间勿操作被测窗口）：

```sh
bash Scripts/verify-ui.sh
```

默认沿用 `/tmp/Liquidmusic-build`，可通过 `LIQUIDMUSIC_DERIVED_DATA` 指定构建目录；`LIQUIDMUSIC_SOURCE_PACKAGES` 可指定已解析的 SourcePackages 源缓存，脚本的 App/runner 构建均会复用它并禁止更新依赖。脚本先构建 App，再运行自动生成的 LiquidmusicUITests scheme，本地 ad-hoc 签名 UI runner；不使用开发者证书。七项 XCUITest 覆盖原生设置入口/保存/取消/分页、搜索、边栏恢复、窄窗音量/队列、真实文件面板取消，以及合成 WAV 导入后的长曲名、专辑/艺术家导航、鼠标定位与左右各 5 秒跳转、歌词界面入口（2026-10-23 更新后尚未重跑桌面用例）。测试按构建路径启动隔离 App，不连接真实库、媒体键或菜单栏；只在自己的临时目录生成全零 PCM，并将 UI 音量调为零。这些自动操作不能代替听音、VoiceOver、Dock/媒体键及签名沙盒人工验收。

验证环境：Xcode 27.1 / Swift 6.4，macOS 27.0.1。2026-10-22 的 Debug 构建与完整 135 项逻辑/集成通过，包含 1/6/12 秒真实静音 AVPlayer 时序、WAV/M4A 双向切换、短 MP3、准备解码失败、替代媒体命令、偏好重开恢复和旧库迁移。测试 FLAC 元数据可读但被本机解码器拒绝，已验证失败处理，未计为交叉播放成功。设置四页与浅深色预览已检查；显示恢复后定向设置 UI 仍在启用自动化模式时超时，用例未开始，最终分页点击修正尚待重验。前一轮六项 M7 UI 的通过记录仍是历史结果。实际听音、完整键盘/VoiceOver、签名沙盒、菜单栏开关与系统级交互仍需人工验收，详情见验收记录。
